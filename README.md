## What is SF_Magic8Ball?

SF_Magic8Ball preserves the original addon concept while updating it for Minecraft 1.21.11+, current Paper-family servers, and modern Slimefun APIs.

Features include:

- a craftable Slimefun Magic 8 Ball;
- randomized answers when used;
- sound and particle feedback for positive, neutral and negative answers;
- Geo resource integration for Magic 8 Ball fragments;
- English-only maintained source/resources;
- removal of obsolete updater and utility-library coupling.

---
## Download and build

Release JARs use the maintained Slimefun-addon naming convention:

`SF_Magic8Ball1.0.0.jar`

The project builds with **Java 25** while targeting **Java 21 bytecode**. The production compatibility baseline is **Slimefun Legacy 4.1.48 on Paper 26.2**. Development builds are available from GitHub Actions and versioned release JARs are published on the Releases page.

---
## Compatibility

Primary target: **Slimefun Legacy**.

Compatibility is also validated against Slimefun United, SlimefunGuguProject/Slimefun4, and original Slimefun4-compatible APIs. Paper is the primary server family; Purpur, Folia and Leaf are compatibility targets.

The maintained fork intentionally avoids external Slimefun utility-library dependencies and keeps cross-fork support on the shared Slimefun addon API wherever practical.
